# menubar-spacer

macOS のメニューバーアイコンの間隔を調整し、元の状態へ正確に戻すアプリです。

macOS にはこの設定がありません。アイコンが増えて表示が詰まったとき——特にノッチ搭載機で
アプリメニューと衝突するとき——動かせるのは非公開のグローバル設定 2 つだけです。
menubar-spacer はその 2 つを変更し、変更前の状態を記録して、いつでも元に戻します。

## 動作要件

- macOS 27 以降、Apple Silicon。Developer ID 署名と Apple notarization 済み
- 権限は一切不要。アクセシビリティ・画面収録・フルディスクアクセスのいずれも要求せず、
  管理者権限もネットワーク通信も使いません。

## できること

| | |
|---|---|
| プリセット | 最小 (4) / 狭い (8) / OS 既定 / 広い (24) — [見え方の比較](docs/ja/preset-appearance.ja.md) |
| 選ぶ前に見比べる | 4 プリセットすべてを、見本アイコン 6 個ずつ・左端を揃えて同時に描画。幅はこの macOS での実測値で、現在有効なものには印が付く |
| 元に戻す | 最初の変更前に記録した状態へ復元（「未設定」だった場合は未設定に戻す） |
| 常駐 | しない。起動して選んで終了するだけ |

指定した値は `NSStatusItemSpacing` と `NSStatusItemSelectionPadding` の両方に、
現在のユーザーの、この Mac のグローバル設定に対してのみ書き込みます。
それ以外は何も書き換えません。

macOS 27.0 での実測値（ステータス項目の幅が 21pt のテストアプリ）:

| 設定値 | 未設定（OS 既定） | 4 | 8 | 24 |
|---|---:|---:|---:|---:|
| 項目の幅 | 37pt | 25pt | 29pt | 45pt |

おおよそ `幅 ≒ アイコン + 値` の関係で、OS 既定は 16 相当にあたります。
アイコンを 6 個並べると、最小で 174px・既定で 246px を占めます
（[撮影した比較](docs/ja/preset-appearance.ja.md)）。

## 制約

- **macOS 標準のアイコンは従いません。** Wi-Fi・バッテリー・時計・コントロールセンター・
  入力メニューは、この設定を何にしても間隔が変わらず、サインアウトしても変わりません。
  動くのは他のアプリケーションのアイコンだけです。
- **変更が反映されるのは、そのアプリを次に起動したときです。** 間隔はアプリの起動時に
  固定されるため、動作中のアプリは終了して開き直すまで元の間隔のままです。
  **一度にすべてへ反映するにはサインアウトして入り直してください** — メニューバーの
  アイコンの多くは個別に終了できないヘルパーが持っています。
  menubar-spacer が何かを終了させることはありません。
- **すべてのアプリが従うかは未確認です。** 確認は自作の AppKit テストアプリで行いました。
  複数ディスプレイ、項目があふれたときの挙動は未検証です。
- **この設定は非公開です。** Apple のサポート対象ではなく、macOS の更新で挙動が変わる、
  あるいは無視される可能性があります。書き込み後に値を読み返し、効かなかった場合はその旨を表示します。
- 2 つのキーは常に同時に変更します。個別の効果は分かっていません。
- 設定は現在のユーザー・現在の Mac にのみ作用します。

## アンインストールする前に

**先に「Undo my changes」を押してください。** アプリを削除しても間隔は元に戻りません
——この設定は macOS のものであってアプリのものではないからです。変更前の状態の記録は
`~/Library/Application Support/jp.nlink.menubar-spacer/` に残ります（アプリをゴミ箱へ入れても、
`brew uninstall --zap` でも消えません）。アプリを入れ直せば Undo が使え、アプリが無くても
次のコマンドで macOS 既定には戻せます。

## アプリを使わずに元に戻す

アプリを削除したあとで間隔が変わったままになっている場合は、次のコマンドで既定に戻ります。

```bash
defaults -currentHost delete -g NSStatusItemSpacing; defaults -currentHost delete -g NSStatusItemSelectionPadding
```

実行後、対象のアプリを終了して開き直すか、一度ログアウトしてください。

## ソースからのビルド

```bash
make test        # 単体テスト
make run         # デバッグ実行
make build-app   # 署名済み .app を dist/ に生成
```
